# Blog SEO Foundation R20.2

## Objective

The QuiConvert blog should answer practical document questions and lead readers
to the relevant category or tool page. Articles must add useful explanations,
examples, checks, and limitations instead of repeating the short text already
present on tool pages.

## Initial WordPress structure

- Posts page: `/blog/`
- Initial post category: `PDF Guides`
- Category slug: `pdf-guides`
- First article slug: `how-to-organize-pdf-pages`

Start with one broad post category. Creating four nearly empty category archives
would add thin pages without helping readers. Split the blog into Organization,
Optimization, Security, and Editing categories only after each topic has at
least three useful articles.

If the site has no existing blog posts, the optional WordPress post permalink
structure `/blog/%postname%/` can be chosen before publishing. Do not change an
established permalink structure without preparing redirects.

## Publishing standard

Each article should include:

1. One descriptive post title rendered as the only H1.
2. A direct answer in the opening paragraph.
3. Clear H2 sections organized around reader tasks.
4. One practical example or workflow.
5. Descriptive internal links to one category hub and two to five relevant tools.
6. A limitations or verification section where appropriate.
7. A short FAQ based on questions actually answered in the article.
8. A concise call to action that matches the article topic.
9. A unique SEO title and meta description in Yoast.
10. A manual mobile check before publication.

Avoid generic anchors such as "click here." Do not repeat the same keyword in
every heading or create articles only to increase word count.

## Internal linking pattern

- Blog post → relevant category hub.
- Blog post → relevant individual tools.
- Category hub → individual tools.
- Individual tool → category hub.
- A later related-article block can link tool pages back to useful guides.

The first article links to the Organize PDF hub and its seven tools. Future
articles should link only where the destination helps the current task.

## First article metadata

- Post title: `How to Organize PDF Pages Online: A Practical Guide`
- Slug: `how-to-organize-pdf-pages`
- Category: `PDF Guides`
- Focus keyphrase: `how to organize PDF pages`
- SEO title: `How to Organize PDF Pages Online | QuiConvert`
- Meta description: `Learn how to merge, split, reorder, delete, duplicate, extract, or reverse PDF pages and choose the right QuiConvert tool for each task.`
- Suggested excerpt: `A practical guide to choosing the right PDF organization tool for combining documents, changing page order, or keeping only the pages you need.`

The accompanying HTML file contains article-body markup only. The WordPress
post title supplies the H1, so the body begins with paragraphs and H2 headings.
